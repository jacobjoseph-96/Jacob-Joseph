# Jacob Joseph — Portfolio

Personal portfolio site for Jacob Joseph, ADAS & Embedded Systems Specialist.
Static HTML + Tailwind CSS, no framework, no build server.

One Piece themed: light is an aged sea chart, dark is the Grand Line at night.

## Features

- Light / dark theme with a smooth cross-fade powered by the View Transitions API (with a per-property transition fallback for older browsers). Light is the default; dark is opt-in and sticky.
- Bilingual content (EN / DE), including the themed section labels.
- Responsive single-page layout: sidebar nav on desktop, top bar + drawer on mobile.
- Scroll-spy navigation, scroll-reveal animations, and a marquee ticker strip.
- A Log Pose corner indicator whose needle points at the section you're reading.
- The hero photo sits in a WANTED bounty poster; the contribution graph is embedded as a live sea chart (see Grand Line banner below).
- Theme tokens centralized as CSS variables in `input.css` — one source of truth for both modes.

## Stack

- HTML (static)
- Tailwind CSS 3.4
- Vanilla JS (`assets/js/main.js`)

## Development

Install dependencies:

```
npm install
```

Watch and rebuild CSS on change:

```
npm run dev
```

One-off production build (minified):

```
npm run build
```

Then open `index.html` in a browser (or serve the directory with any static server).

## Theming

Theme variables live at the top of [input.css](input.css) under `html.dark` and `html.light`.
Add or change a token in both blocks; every component reads from `var(--token)` so no
class-level overrides are needed. Re-run `npm run build` after editing.

The palette is the One Piece skin, ported from the `onepiece-dark` / `onepiece-light` token
sets in [github.com/jacobjoseph-96](https://github.com/jacobjoseph-96) → `src/theme.mjs`, so
this site and the GitHub profile render the same world:

| | light — aged sea chart | dark — Grand Line at night |
|---|---|---|
| page | `#f3e4c3` parchment | `#07161f` deep water |
| accent | `#c1121f` poster crimson | `#2a9d8f` sea teal |
| gold | `#b8860b` | `#ffb703` |

The accent role flips between modes on purpose: teal is the sea, crimson is the ink on a
wanted poster.

Two things are worth knowing before editing this file:

- The markup was authored against Tailwind's `slate-*` and `blue-*` scales. Rather than
  rewrite hundreds of class attributes, both scales are re-pointed at theme tokens by a
  class map further down `input.css`. Change the token, not the markup.
- Tailwind emits its `hover:` / `group-hover:` variants *after* the plain CSS in this file,
  so an equal-specificity override loses on source order. Those rules carry an `html` prefix
  to win on specificity instead — keep it when adding new hover overrides.

The theme toggle in [assets/js/main.js](assets/js/main.js) wraps the class swap in
`document.startViewTransition(...)` so the page cross-fades smoothly between modes.

## Grand Line banner

The contribution graph in the Profile section is generated by
[github.com/jacobjoseph-96](https://github.com/jacobjoseph-96) from real GitHub contribution
data, rebuilt daily by that repo's workflow (cron 03:17 UTC) and force-pushed to its `output`
branch. This page hotlinks that branch, so it picks up a fresh chart every day with no
redeploy here.

There are two variants, `grandline-light.svg` and `grandline-dark.svg`. A
`<picture media="(prefers-color-scheme: …)">` would desync from the toggle button, because
this site's theme is class-toggled rather than OS-driven — `setTheme()` in
[assets/js/main.js](assets/js/main.js) swaps the `src` instead, which also means only the
variant actually on screen is ever fetched.

## Internationalization

Strings are keyed via `data-i18n="..."` attributes in the markup and resolved from
the language files under `assets/i18n/` (`en.json`, `de.json`).
